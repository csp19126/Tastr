# Tastr – the phone app

Expo (React Native) app for iPhone, Android and web. See the main [README](../README.md) for how to run it.

- Screens: `src/app/` (each file is a screen; `(tabs)/` are the five bottom tabs)
- Words: `src/locales/en.ts` and `src/locales/vi.ts`
- Look and feel: `src/lib/theme.ts`, `src/components/`
- Server address: `src/lib/config.ts` (works it out in development; set `EXPO_PUBLIC_API_URL` for builds)

`AGENTS.md` has notes for AI coding assistants working on this folder.
